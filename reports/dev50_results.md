## 运行质量与成本

- standard: 50 条缓存响应，输入 72552 / 输出 4052 tokens；0 条响应达到长度上限。
- hipporag: 557 条缓存响应，输入 449661 / 输出 51987 tokens；4 条响应达到长度上限。
- HippoRAG: 0/227 文档无实体，0/227 文档无三元组；8/50 问题无图种子。
- 空抽取是异常代理指标，不等同于已确认的解析错误；截断统计包含所有 LLM 阶段。
- 全部使用本地模型，无外部模型 API 费用。HippoRAG 本轮复用适配探索阶段的 NER 原始响应缓存，建索引秒数不是冷启动值，不能直接比较完整建索引成本。缓存库存 token 含继承的响应，也不等于本轮新生成量；JSON 另记录相对导入缓存新增的响应用量。耗时还受模型服务 KV 缓存、系统负载和调用顺序影响。
